# UI/UX и процедурная отрисовка

Клиент строится на **чистом TypeScript + HTML/CSS + Canvas2D** без сторонних UI-фреймворков. Полноэкранный `<canvas>` занимает 100% окна, а поверх него располагаются лёгкие HTML-оверлеи (`pointer-events` пропускают клики на канвас там, где нет элементов интерфейса).

---

## 1. Экраны и состояния интерфейса

1. **Лобби (стартовый экран):**
   - Поле ввода ника (для быстрого гостевого входа за 1 клик) и кнопка «Играть».
   - Кнопки «Войти / Профиль» и «Глобальный лидерборд» (Этап 2).
   - На фоне канвас может рендерить сетку арены.
2. **Игровой HUD:**
   - **Верхний левый угол:** Энергия (и текущий доход/сек), уровень + шкала XP, счётчик армии (`текущие / лимит`).
   - **Верхний правый угол:** лидерборд текущего матча (Топ-5/10) + кнопка/переключатель Debug-оверлея (FPS, пинг RTT, число сущностей).
   - **Низ по центру:** панель строительства (иконки зданий, стоимость, хоткеи `1–4`) и переключатель режима армии (`[Q]` Защита базы / Точка сбора).
   - **Контекстная карточка здания:** при клике `ЛКМ` по своей постройке — компактное окно «Улучшить (цена) / Продать (+возврат)».
   - **Нижний левый угол (Этап 2):** панель прокачки 6 характеристик (подсвечивается при наличии свободных очков уровня).
3. **Экран поражения (`GameOver`):**
   - Итоги забега: очки, время жизни, убийства, разрушенные здания.
   - Кнопки «Играть снова» и «В лобби».
4. **Модальные окна (Этап 2):**
   - Форма Входа / Регистрации.
   - Профиль игрока (агрегированная статистика + последние 10 матчей).
   - Глобальный лидерборд.

## 2. Процедурная отрисовка на Canvas2D (по слоям)

Отрисовка выполняется без растровых спрайтов, в строгом порядке слоёв:

1. **Фон и арена:** матовая подложка, координатная сетка (движется вместе с камерой) и чёткая круговая граница карты.
2. **Зоны владения:** полупрозрачные круги цвета владельца с обводкой. При активной защите новичка (бит 0 в `flags`) — мягко пульсирующее внешнее кольцо.
3. **Оверлеи планирования:**
   - При выбранной стройке: полупрозрачный силуэт под курсором (зелёный — можно строить, красный — нельзя) + радиус действия для турели.
   - Флажок/маркер текущей точки сбора армии (`Rally Point`).
4. **Постройки (геометрические примитивы с контуром):**
   - *Штаб (HQ)* — крупный шестиугольник.
   - *Генератор* — круг с вращающимся внутренним кристаллом.
   - *Турель* — круглая база + ствол, повёрнутый на декодированный `angle`.
   - *Казарма* — квадрат со срезанными углами.
   - *Стена* — плотный восьмиугольник.
   - Уровень постройки (`1–3`) отображается количеством внутренних колец или насечек.
5. **Юниты и снаряды:** юниты — компактные круги/треугольники цвета игрока; снаряды — яркие точки/капли.
6. **HP-бары и эффекты:** полоски здоровья рисуются **только у повреждённых объектов** (`hp < max_hp`), чтобы не засорять экран. При исчезновении сущности (смерть/разрушение) клиент проигрывает короткое расходящееся кольцо/вспышку.

## 3. Камера, интерполяция и управление (ПК + планшет/тач в MVP)

- **Интерполяция:** клиент хранит два последних снэпшота (`prev` и `curr`, приходят раз в 50 мс) и в `requestAnimationFrame` вычисляет `lerp(prev, curr, alpha)` для плавных 60+ FPS.
- **Камера (ПК):** перемещение `WASD` / стрелками или перетаскиванием средней кнопкой мыши (`СКМ`), зум колёсиком мыши (с ограничениями `min/max`), `Space` — центрировать камеру на своём Штабе.
- **Камера (Планшет/тач):** перетаскивание 1 пальцем (`> 10px`) перемещает камеру, 2 пальца (pinch) плавно зумируют (`touch-action: none` на канвасе), кнопка `База` центрирует на Штабе.
- **Стройка:** выбор здания (`1–4` или тап/клик по панели) → тап/`ЛКМ` поставить → `ПКМ` / `Esc` / кнопка `Отмена` закрывает режим стройки. При выборе своей постройки открывается карточка «Улучшить / Продать».
- **Армия:** `ПКМ` по карте (или тап в режиме кнопки `Атака`) устанавливает точку сбора (`Rally Point`); `Q` или кнопка `Защита` возвращает армию на защиту базы.
- **Мобильный HUD:** все интерактивные кнопки имеют размер не менее `44×44 px` и отступы `env(safe-area-inset-*)`.
