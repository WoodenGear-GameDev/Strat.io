# Stratio v2 — Спецификация

Полная спецификация переписываемого проекта **Stratio**, проработанная пошагово. Старый проект сохранён в [old/](file:///data/user/0/com.agy/files/projects/Stratio/old) в качестве референса визуального стиля и проверенных технических приёмов.

## Разделы спецификации
1. [01-overview.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/01-overview.md) — Обзор проекта, режимы (Online .io / Offline / LAN), платформы и стек.
2. [02-world.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/02-world.md) — Мир, 3 кольца, гравитация массы, полярная навигация, туман войны и «красный туман» на миникарте.
3. [03-base-and-economy.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/03-base-and-economy.md) — Гекс-сетка, 2-треугольные генераторы (3-в-1), связность по граням, Узлы, отрыв, Энергия, Эссенция в Ядре и «Реген базы».
4. [04-drones-teleport-camera.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/04-drones-teleport-camera.md) — Фабрики, потеря лимита контроля, автокластеризация отрядов, автоподкрепление, телепорт с зарядкой и «замирающая» камера.
5. [05-modifiers.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/05-modifiers.md) — 4 ветки модификаторов: Кукловод, Стелсер, Рубака, СДВГшник.
6. [06-pve-and-bots.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/06-pve-and-bots.md) — Агрессивные ульи, Курсирующие зоны подавления, Точки притяжения и честные ИИ-боты.
7. [07-controls-and-ui.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/07-controls-and-ui.md) — Управление ПК + смартфон, WebGL2 (120+ FPS), HUD, экраны и мета-функции.
8. [08-architecture-and-roadmap.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/08-architecture-and-roadmap.md) — Техническая архитектура, требования 120+ FPS, серверный туман войны и план реализации.
9. [09-system-design.md](file:///data/user/0/com.agy/files/projects/Stratio/docs/spec/09-system-design.md) — Детальная структура файлов, конвейер тика, поток данных и инженерные стандарты против спагетти.
