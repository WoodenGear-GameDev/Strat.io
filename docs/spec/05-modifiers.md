# 05. Модификаторы (4 ветки развития)

## 1. Общие правила
- **Открытие:** первый модификатор выбирается при переходе во 2-е кольцо (2 ур. Ядра). Остальные модификаторы докупаются за **Эссенцию** с прогрессивным ростом цены за каждый следующий.
- **Формат:** модификаторы работают как **чертежи новых модулей** (не глобальные пассивки). Они занимают гексы базы и питаются из общего бака Энергии.
- **Прокачка:** все спецмодули имеют **3 уровня** прокачки за Энергию (с тем же правилом потолка `Уровень Ядра + 1`).
- *Примечание:* текущие названия веток — рабочие, при необходимости могут быть переименованы позже.

## 2. Ветки и их модули

### Кукловод (Спец-фабрика)
- **Модуль:** специализированная фабрика (1 гекс) с **переключателем роли** дронов в меню фабрики.
- **Роли (рабочие названия, детали поведения и статов уточняются при балансе):**
  - **Танки (осадники):** медленные, живучие, приоритет по вражеским зданиям и перешейкам.
  - **Рейдеры (перехватчики):** быстрые, вырезают чужих разведчиков и лишают врага обзора/телепорта.

### Стелсер (Гекс-глушилка)
- **Модуль:** гекс-глушилка (1 гекс). Достаточно **одной глушилки** на базу.
- **Эффект:** сильно сжимает радиус обнаружения базы и её юнитов в тумане войны (враг видит их почти вплотную).
- **Цена и ограничения:**
  - пассивный расход Энергии самой глушилкой;
  - **надбавка к стоимости в Энергии** за каждого выпускаемого дрона;
  - глушилка **отключается**, если не хватает Энергии или **база находится под атакой**; стрельба и телепорт временно сбрасывают маскировку.

### Рубака (Анти-базовая пушка)
- **Модуль:** тяжёлая пушка (1 гекс).
- **Эффект:** стреляет **автоматически** и **строго только по вражеским зданиям** (высокий урон по постройкам, не стреляет по дронам).
- **Тактика:** либо осадный поук с повышенной дальностью, либо врыв в упор в связке с телепортом / движками СДВГшника.

### СДВГшник (Гексы-движки)
- **Модуль:** движок (1 гекс) для свободного поступательного движения базы (**омни-дрейф без вращения сетки**).
- **Эффект:** расходует Энергию при движении; скорость пропорциональна соотношению числа/уровня движков к общему числу гексов базы.
- **Взаимодействие с миром:**
  - **не отключает телепорт** (можно комбинировать);
  - при столкновении с другими базами или ульями работает физическое отталкивание **без таранного урона**.
