# 01. Обзор проекта, рамки и технологический стек

## 1. Концепция
**Stratio** — аркадная стратегия в стиле `.io` на круглой полярной арене с кольцами прогрессии. Игрок строит базу из гексагональных модулей вокруг Ядра, соблюдая правило связности, управляет отрядами дронов в условиях тумана войны, развивает один или несколько специализированных модификаторов и сражается за контроль над внутренними кольцами.

## 2. Игровые режимы
- **Основной режим (Online .io):** персистентная арена с непрерывным входом/выходом игроков. При уничтожении Ядра игрок начинает новый забег с внешнего кольца.
- **Оффлайн-режим:** локальная симуляция (через WASM / локальное ядро) против полноценных ИИ-ботов и PvE-экосистемы.
- **Локальная сеть (LAN):** возможность поднять локальный сервер и играть по сети.
- **Боты (приоритет):** основательно проработанный ИИ-заполнитель арены (умеет строиться по гекс-правилам, выбирать модификаторы, реагировать на PvE, разведывать и атаковать), чтобы арена ощущалась живой даже при низком онлайне.

## 3. Целевые платформы
1. **Приоритет 1 — Веб-браузер (ПК + смартфоны):** управление и интерфейс изначально проектируются под оба форм-фактора без урезания механик.
2. **Приоритет 2 — Нативные обёртки:** Desktop и Mobile (на базе Tauri / WebView) поверх того же веб-клиента и Rust-ядра.

## 4. Технологический стек
- **Игровое ядро (`game-core`):** Rust — единая детерминированная симуляция для сервера и оффлайн-WASM.
- **Серверная часть:** Rust (игровой узел + мета/матчмейкинг при необходимости).
- **Клиент:** TypeScript + Web-рендер (Canvas / WebGL), визуальный стиль опирается на референс из `old/`.
- **Конфигурация баланса:** декларативные конфиги (JSON/TOML), разделённые с логикой симуляции.

## 5. Принципы переписывания
- Старый проект сохранён в `old/` исключительно как референс визуального стиля и проверенных технических приёмов.
- Вся архитектура, протокол, симуляция и UX проектируются с нуля по утверждённой спецификации в `docs/spec/`.
