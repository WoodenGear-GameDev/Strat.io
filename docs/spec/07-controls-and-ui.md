# 07. Управление (ПК + смартфон) и UI/UX

## 1. Визуальный стиль и рендер
- **Стиль и рендер:** процедурный геометрический рендер на базе визуального референса из `old/` (чистый TypeScript + **оптимизированный Canvas2D** с `alpha: false`, `0.25x` offscreen туманом войны и субкадровой интерполяцией). Целевая производительность — **120+ FPS** на ПК и 120Hz смартфонах (обновление HTML-HUD только при изменении значений).
- **UI-слой:** лёгкий HTML/CSS HUD поверх полноэкранного `<canvas>` (`pointer-events` пропускают ввод в игру). Все интерактивные элементы мобильного интерфейса `>= 44×44 px` с учётом `env(safe-area-inset-*)`.
- **Читаемость:** полоски HP отображаются только у повреждённых модулей/юнитов; уровни зданий (`1–3`) и типы модификаторов читаются напрямую по геометрии модулей.

## 2. Схема управления (ПК и смартфон)
- **Камера:**
  - *ПК:* `WASD` / стрелки или перетаскивание мышью (`СКМ`/зажатие), зум колёсиком, `Space` — центрировать на активном фокусе, `Tab` — переключить фокус (База ↔ Отряды).
  - *Смартфон:* перетаскивание 1 пальцем (`> 10px`) двигает камеру, 2 пальца (pinch) — свободный зум.
- **Фокус (База и Отряды):**
  - Панель динамических чипов в HUD: `[База] [Отряд 1] [Отряд 2] ...`.
  - Выбор отряда открывает его быстрые действия: **«Автоподкрепление»** (вкл/выкл до ручной отмены) и **«Домой (Патруль)»**.
- **Приказы дронам (цели):**
  - *Смартфон:* короткий **тап** по карте (когда не активны режимы стройки/телепорта/движения базы) ставит метку цели выбранному отряду (или отправляет патруль базы).
  - *ПК:* `ПКМ` по карте.
- **Движение базы (СДВГшник):**
  - Управляется через **точку назначения** (при наличии движков в базе — режим/команда указания точки, куда базе плыть омни-дрейфом; универсально для ПК и тача).
- **Стройка и управление модулями:**
  - Нижняя панель выбора модуля (базовые + открытые модификаторы) с подсветкой допустимых гексов и 3 ромбо-секторов для Генераторов.
  - Контекстное меню выбранного модуля: `Улучшить` / `Снести` (+ для Фабрики: `Пауза` и `Переключатель Танк / Рейдер`; для Ядра: `Улучшить Ядро`, `Реген базы (вкл/выкл)`, выбор/покупка модификаторов).
- **Телепорт:**
  - Кнопка в HUD (хоткей `T`) → подсветка видимой области → отображение стоимости по дистанции → подтверждение кликом/тапом.

## 3. Экраны и мета-функциональность
- **Лобби:** быстрый гостевой вход по нику, выбор режима (Online / Offline / LAN), вход/регистрация аккаунта, профиль, глобальный лидерборд.
- **Игровой HUD:**
  - Энергия (`текущая / лимит`, доход/с), Эссенция (хранимая в Ядре), лимит дронов;
  - Миникарта (кольца, база, отряды, световые сигналы Точек притяжения, красный туман затяжных боёв);
  - Топ-лидерборд текущей арены;
  - Панель фокуса (База / Отряды) и панель стройки;
  - Индикатор доступности апгрейда Ядра / нового модификатора.
- **Экран поражения (`GameOver`):** статистика забега, сохранение результата в профиль/лидерборд, кнопки «Играть снова» и «В лобби».
- **Аккаунты, лидерборды и БД:** обязательная часть продукта (закладываются в архитектуру с самого начала).
