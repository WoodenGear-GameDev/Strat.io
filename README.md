# Stratio

Аркадная стратегия в `.io`-стиле с авторитарным сервером на Rust и лёгким веб-клиентом.

> [!NOTE]
> **Границы проекта:** Этапы 0–2 формируют минимальный сетевой MVP для сдачи лабораторной работы. Этапы 3–4 — пост-MVP расширение (центральное ядро, движение зон, уникальные блоки, боты, Telegram Mini App, PWA/WASM-офлайн, LAN).
> Автоматические тесты по решению команды не пишутся — проверка выполняется через сборку (`cargo check`, `npm run build`) и ручной прогон (включая мульти-вкладочный тест).

## Технологический стек

- **Игровое ядро (`game-core`):** Rust (чистая детерминированная симуляция без зависимостей от сети, ОС и БД).
- **Игровой узел (`game-node`):** Rust, Axum + Tokio (WebSocket-сервер, цикл 20 TPS, локальная проверка JWT).
- **Мета-сервер (`meta-server`):** Rust, Axum + Tokio + SQLite (`sqlx`) для аккаунтов, профилей, истории матчей и лидербордов.
- **Офлайн-модуль (`game-wasm`):** Rust → WebAssembly (заглушка в MVP, полноценный офлайн-режим на Этапе 3).
- **Веб-клиент (`client/`):** чистый TypeScript + HTML/CSS + Vite + Canvas2D (процедурная графика, без фронтенд-фреймворков).
- **Десктоп (`src-tauri/`):** тонкая обёртка Tauri вокруг собранного веб-клиента (Этап 2).

```text
│   ├── meta-server/            ← HTTP API + SQLite (аккаунты, профили, лидерборд)
│   └── game-wasm/              ← WASM-обёртка над game-core для офлайна
├── client/                     ← Веб-клиент (Vanilla TS + Vite + Canvas2D)
│   ├── src/
│   │   ├── transport/          ← Интерфейс Transport (WsTransport / WorkerTransport)
│   │   ├── game/               ← Протокол, состояние + интерполяция, рендер, ввод
│   │   └── ui/                 ← HTML/CSS оверлеи поверх Canvas
│   └── index.html
└── src-tauri/                  ← Десктопная обёртка Tauri (Этап 2)
```

## Быстрый старт (как запустить и поиграть)

### Требования
- **Rust** (`cargo`, `rustc` 1.78+) — [rustup.rs](https://rustup.rs/)
- **Node.js** 18+ и `npm` — [nodejs.org](https://nodejs.org/)

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/WoodenGear-GameDev/Strat.io.git
cd Strat.io

# Собрать серверные бинарники (debug-сборка быстрая)
cargo build -p meta-server -p game-node

# Установить зависимости веб-клиента
cd client && npm install && cd ..
```

### 2. Запуск (3 терминала)

**Терминал 1 — Мета-сервер** (SQLite + HTTP API, порт `8080`):
```bash
./target/debug/meta-server
```

**Терминал 2 — Игровой сервер** (WebSocket 20 TPS, порт `8081`):
```bash
./target/debug/game-node
```
> Для записи телеметрии матчей в JSONL можно запустить с флагом:
> `STRATIO_LOG_JSONL=logs/live.jsonl ./target/debug/game-node`

**Терминал 3 — Веб-клиент** (Vite, порт `5173`, проксирует `/api` и `/ws`):
```bash
cd client && npm run dev
```

### 3. Открыть игру
Перейдите в браузере на **`http://localhost:5173`** (или `http://127.0.0.1:5173`).

## Управление в игре

### Постройки и база
- `1` / `2` / `3` / `4` — выбрать постройку (Генератор / Казарма / Турель / Маяк с Ядра Ур. 3).
- `U` — режим улучшения зданий, `X` — снос зданий.
- `T` — телепорт базы (возможен только в области взора базы или дронов).
- `Esc` — отменить активный режим.

### Отряды дронов и камера
- **Переключение на дронов (`Space` / кнопка `Ядро ↔ Дроны` / кнопки отрядов `#1`, `#2`, ...):** автоматически включает режим целеуказания — клик/тап по карте отдаёт приказ выбранному отряду.
- `~` — вернуться к Ядру (базовые дроны возвращаются к патрулированию орбиты).
- `Q` / `E` / `Tab` / `5–9` — переключение между активными отрядами.
- **`↻ Подкреп`** (в панели отрядов при выборе боевого отряда) — новые дроны из казарм автоматически летят по полярной дуге на подкрепление к этому отряду.
- **Панорамирование камеры:** перетаскивание ЛКМ/СКМ или свайп 1 пальцем в пределах зоны видимости (работает и в режиме постройки, если жест начат вне области базы). Колесо мыши / щипок 2 пальцами — зум.

## Продакшн-сборка и Tauri
- **Release-сборка:** `cargo build --release -p meta-server -p game-node` и `cd client && npm run build`; пример конфигурации Nginx — [deploy/nginx.conf](deploy/nginx.conf).
- **Десктоп (Tauri v2):** из `src-tauri/` командой `cargo tauri build` (для удалённого сервера задать `VITE_API_BASE_URL` и `VITE_GAME_WS_URL`).
